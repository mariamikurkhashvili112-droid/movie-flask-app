# ფილმების Flask + MongoDB პროექტი

## აღწერა

პროექტი დავწერე Flask-ისა და MongoDB-ის გამოყენებით. მონაცემები (ფილმების სია)
ინახება MongoDB ბაზაში, ხოლო მთავარ გვერდზე ცხრილის სახით ვაჩვენებ მათ.
ფილმის დასახელება და დანარჩენი ინფორმაცია ფერდება რეიტინგის მიხედვით:
მწვანე თუ რეიტინგი 9-ზე მეტია ან ტოლია, ნარინჯისფერი თუ 8.5-დან 9-მდეა,
დანარჩენ შემთხვევაში ნაცრისფერი. ცხრილის ქვემოთ ვაჩვენებ ფილმების საერთო
რაოდენობასაც და საშუალო ხანგრძლივობასაც — ორივე დინამიურად, კოდით ვთვლი.

## პროექტის სტრუქტურა (MVC)

პროექტი დავყავი Model-View-Controller პრინციპით:

```
movie_flask_app/
├── app/
│   ├── models/movie_model.py        → ბაზასთან მუშაობა
│   ├── controllers/movie_controller.py → routes და ლოგიკა
│   ├── templates/index.html         → გვერდის HTML
│   └── static/style.css             → სტილები
├── config.py
├── run.py
├── seed_db.py
└── requirements.txt
```

## გაშვების ინსტრუქცია

1. MongoDB დავაინსტალირე და გავუშვი სერვისი.
2. `pip install -r requirements.txt`
3. `python seed_db.py` — ეს ავსებს ბაზას მოცემული ფილმებით.
4. `python run.py` — უშვებს Flask აპლიკაციას.
5. ბრაუზერში ვხსნი `http://127.0.0.1:5000`-ს და ვხედავ შედეგს.
